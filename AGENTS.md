## Project rules
- The human model GLB is generated by `scripts/generate_human_model.py` (rerun, then re-host with lovable-assets and update `src/assets/models/human-male-rigged.glb.asset.json`); never hand-edit the GLB, so the model stays reproducible.
- Bones use Mixamo `mixamorig:` names; GLTFLoader strips `:` at load, so the viewer matches bones by sanitized name.
- Pose state lives in the plain store in `src/components/viewer/pose-rig.ts` and is applied to bones in `useFrame`, so slider moves never re-render the 3D scene.
- The viewer route uses `ssr: false` because WebGL cannot render on the server.
